## [1.0.0] - 2026-09-17

### Добавлено (Added)
- Потоковое воспроизведение любого `.torrent` файла через TorrServer REST API без предварительной записи на локальный диск.
- Нативный Drag & Drop интерфейс для перетаскивания файлов торрентов прямо из macOS Finder.
- Альтернативный выбор файла через диалоговое окно Finder при клике по зоне загрузки.
- Парсинг структуры многофайловых торрентов и фильтрация видеоконтейнеров (`.mp4`, `.mkv`, `.avi`, `.mov`, `.m4v`, `.wmv`, `.ts`, `.flv`, `.webm`).
- Список серий с индикацией форматированного размера файла и возможность запуска отдельного эпизода.
- Возможность воспроизведения всего сезона целиком в виде M3U-плейлиста (`«▶ Смотреть всё плейлистом»`).
- Горячие клавиши:
  - `⌘+⇧+T` — открытие интерфейса плагина с Drag & Drop зоной.
  - `⌘+⇧+P` — быстрый выбор `.torrent` файла и мгновенный старт первого видео.
- Автоматический поиск запущенного TorrServer на портах `8090` и `8095`, а также автозапуск установленного бинарника в `/opt/homebrew/bin/torrserver` или `/usr/local/bin/torrserver`.
- OSD-уведомления поверх видео в плеере о статусе подключения и загрузки.
- Скрипты сборки (`scripts/build.js`) и упаковки дистрибутивов (`scripts/package.js`).
- Автоматизированный пайплайн GitHub Actions для публикации релизов при создании Git-тегов.
