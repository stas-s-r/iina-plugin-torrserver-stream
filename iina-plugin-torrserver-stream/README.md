# IINA TorrServer Stream Plugin

[![IINA Plugin](https://img.shields.io/badge/IINA-Plugin%20v1.0-blue.svg)](https://iina.io)
[![macOS](https://img.shields.io/badge/Platform-macOS-lightgrey.svg)](https://apple.com/macos)
[![TorrServer](https://img.shields.io/badge/Backend-TorrServer%20MatriX-orange.svg)](https://github.com/YouROK/TorrServer)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Плагин для современного медиаплеера [IINA](https://iina.io) (macOS), обеспечивающий прямое воспроизведение видео из торрентов через локальный или удаленный [TorrServer](https://github.com/YouROK/TorrServer). 

Позволяет смотреть фильмы и серии мгновенно с перемоткой по ключевым кадрам без необходимости предварительного скачивания всего файла на SSD.

---

## ⚡️ Возможности (Features)

- **Drag & Drop из Finder:** Перетащите любой `.torrent` файл прямо в окно плагина или воспользуйтесь нативным диалогом выбора файла.
- **Выбор серии в многофайловых раздачах:** При загрузке сезона сериала плагин парсит структуру раздачи, отфильтровывает видеофайлы и отображает удобный список серий с размером.
- **Воспроизведение плейлистом (M3U):** Запуск всех серий подряд одной кнопкой «Смотреть всё плейлистом».
- **Горячие клавиши:**
  - <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>T</kbd> — Открыть окно загрузки торрентов.
  - <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>P</kbd> — Быстрый запуск (выбор файла в Finder и моментальный старт первого видео).
- **Автоматический запуск бэкенда:** Проверка запущенного экземпляра TorrServer на портах `8090` / `8095` или автоматический подъем установленного в системе демона (`/opt/homebrew/bin/torrserver`, `/usr/local/bin/torrserver`).
- **Бережное отношение к диску:** Потоковое кэширование в оперативной памяти без износа ресурса накопителя.
- **Нативный интерфейс:** Окно стилизовано под дизайн macOS и темную тему IINA.

## 📦 Установка

Подробная пошаговая инструкция с установкой сервера и решением проблем вынесена в файл **[INSTALL.md](INSTALL.md)**.

### Быстрый старт:

1. **Установите TorrServer** (если еще не установлен):
   ```bash
   brew install torrserver
   # запуск как сервис:
   brew services start torrserver
   ```
2. **Скачайте плагин:**
   Загрузите архив **`torrserver-stream.iinaplgz`** из раздела [Releases](../../releases).
3. **Установите в IINA:**
   Дважды кликните по файлу `torrserver-stream.iinaplgz` в Finder. IINA откроет окно подтверждения — нажмите **Установить**.
4. **Активация:**
   В IINA перейдите в **Настройки (⌘,) → Плагины** и убедитесь, что плагин **TorrServer Stream** включен.

## 🚀 Использование

### Способ 1: Интерактивное окно (Рекомендуется для сериалов)
1. Нажмите <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>T</kbd> (или в строке меню: **Плагины → TorrServer: Открыть окно загрузки...**).
2. Перетащите `.torrent` файл в пунктирную область или кликните по ней для выбора файла в Finder.
3. Дождитесь опроса метаданных: плагин отобразит название раздачи и список видеофайлов.
4. Нажмите на нужную серию для запуска либо выберите **«▶ Смотреть всё плейлистом»**.

### Способ 2: Мгновенный запуск
1. Нажмите <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>P</kbd> (или **Плагины → TorrServer: Выбрать .torrent и сразу смотреть**).
2. Выберите файл торрента в стандартном окне Finder.
3. Воспроизведение начнется автоматически.

## 🏗 Архитектура решения

```
┌─────────────────────────────────────────────────────────────┐
│                      IINA Media Player                      │
│                                                             │
│  ┌───────────────────────┐       ┌───────────────────────┐  │
│  │   UI (WebView / HTML) │       │    Global Entry JS    │  │
│  │   - Drag & Drop Zone  │ <───> │    - Daemon Manager   │  │
│  │   - Episode Picker    │  IPC  │    - Menu Hotkeys     │  │
│  └───────────────────────┘       └──────────┬────────────┘  │
│                                             │               │
│                                     REST API (Upload/Stats) │
│                                             │               │
│  ┌───────────────────────┐                  ▼               │
│  │   mpv Stream Engine   │ <──────── TorrServer             │
│  │   (HTTP Range Stream) │    HTTP   (Local / Remote)       │
│  └───────────────────────┘                  │               │
└─────────────────────────────────────────────┼───────────────┘
                                              ▼
                                      BitTorrent Swarm
```

- **Plugin Runtime (Global Entry):** Инициализирует глобальное меню, горячие клавиши, проверяет доступность TorrServer, декодирует Base64-данные при drag-and-drop и отправляет multipart-запрос загрузки торрента в REST API сервера.
- **WebView UI:** Обеспечивает нативное взаимодействие с пользователем через двунаправленный IPC-мост (`standaloneWindow.onMessage` / `postMessage`).
- **TorrServer:** Скачивает фрагменты торрента последовательно (sequential download), кэширует их в RAM и отдает плееру по протоколу HTTP с поддержкой Range-запросов.

## 🛠 Сборка из исходников

Для самостоятельной сборки и упаковки плагина требуется [Node.js](https://nodejs.org) (v18+):

```bash
# Клонирование репозитория
git clone https://github.com/username/iina-plugin-torrserver-stream.git
cd iina-plugin-torrserver-stream

# Сборка JS-бандлов и валидация синтаксиса
npm run build

# Упаковка в .iinaplugin директорию и .iinaplgz архив
npm run package

# Упаковка и автоматическая установка в локальный каталог плагинов IINA
node scripts/package.js --install
```
