# iina-plugin-torrserver-stream
Плагин для современного медиаплеера [IINA](https://iina.io) (macOS), обеспечивающий прямое воспроизведение видео из торрентов через локальный или удаленный [TorrServer](https://github.com/YouROK/TorrServer).   Позволяет смотреть фильмы и серии мгновенно с перемоткой по ключевым кадрам

[Архив для установки](https://github.com/stas-s-r/iina-plugin-torrserver-stream/blob/main/iina-plugin-torrserver-stream/torrserver-stream.iinaplgz)



# Руководство по установке TorrServer Stream для IINA

Данный документ содержит исчерпывающее руководство по установке плагина, настройке сервера потокового вещания TorrServer на macOS и решению возможных проблем.

---

## 📋 Системные требования

- **macOS:** 10.15 (Catalina) или новее (поддерживаются Apple Silicon M1/M2/M3/M4 и Intel).
- **Медиаплеер IINA:** версия **1.3.0** или новее (с поддержкой Plugin System).
- **TorrServer MatriX:** версия 120 или новее (локально или на сетевом накопителе/сервере).

---

## Шаг 1: Установка и запуск TorrServer

Плагин использует TorrServer в качестве легковесного P2P-прокси, который последовательно запрашивает фрагменты видео у сидов и отдает их плееру через HTTP-поток.

### Вариант А: Через Homebrew (Рекомендуется)

Самый простой и надежный способ для пользователей macOS:

```bash
# Установка TorrServer
brew install torrserver

# Запуск в фоновом режиме как службы (будет автоматически стартовать при входе в систему)
brew services start torrserver
```

Проверить работу можно, открыв в браузере: [http://127.0.0.1:8090](http://127.0.0.1:8090). Должен открыться веб-интерфейс TorrServer.

### Вариант Б: Запуск бинарного файла вручную

Если вы не используете Homebrew:

1. Перейдите в официальный репозиторий [TorrServer Releases](https://github.com/YouROK/TorrServer/releases).
2. Скачайте бинарник для вашей архитектуры:
   - Для Apple Silicon (M1/M2/M3/M4): `TorrServer-darwin-arm64`
   - Для процессоров Intel: `TorrServer-darwin-amd64`
3. Переименуйте скачанный файл в `torrserver`, сделайте его исполняемым и переместите в путь поиска:
   ```bash
   chmod +x TorrServer-darwin-*
   sudo mv TorrServer-darwin-* /usr/local/bin/torrserver
   ```
4. При первом запуске плагин автоматически сможет вызвать `torrserver`, если он расположен в `/opt/homebrew/bin/torrserver` или `/usr/local/bin/torrserver`.

### Вариант В: Удаленный сервер или NAS / Docker

Если у вас уже работает TorrServer в локальной сети (на роутере, NAS Synology/QNAP или в Docker-контейнере), плагин автоматически проверяет стандартный порт `8090` на localhost. Для перенаправления можно использовать SSH-туннель:
```bash
ssh -L 8090:127.0.0.1:8090 user@nas-ip
```

## Шаг 2: Установка плагина в IINA

### Способ 1: Установка через готовый архив `.iinaplgz` (One-Click)

1. Перейдите на страницу [GitHub Releases](https://github.com/stas-s-r/iina-plugin-torrserver-stream/blob/main/iina-plugin-torrserver-stream/torrserver-stream.iinaplgz).
2. Скачайте файл **`torrserver-stream.iinaplgz`**.
3. Дважды кликните по загруженному файлу в Finder.
4. В появившемся диалоговом окне IINA нажмите **«Установить»** (Install).

### Способ 2: Ручная установка директории плагина

1. Скачайте или соберите папку `torrserver-stream.iinaplugin`.
2. В Finder нажмите <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>G</kbd> и перейдите по пути:
   ```
   ~/Library/Application Support/com.colliderli.iina/plugins/
   ```
3. Скопируйте папку `torrserver-stream.iinaplugin` (или переименуйте в `org.colliderli.torrserver-stream.iinaplugin`) в эту директорию.
4. Перезапустите IINA.

### Способ 3: Сборка и установка из исходников

Если у вас установлен Node.js:
```bash
git clone https://github.com/username/iina-plugin-torrserver-stream.git
cd iina-plugin-torrserver-stream
node scripts/package.js --install
```
Скрипт скомпилирует бандлы, сформирует архив и скопирует плагин напрямую в каталог плагинов IINA.

---

## Шаг 3: Проверка и активация

1. Запустите IINA.
2. Откройте **Настройки (⌘,) → Плагины**.
3. Найдите в списке **TorrServer Stream** и убедитесь, что чекбокс рядом с ним активен (включен).
4. Проверьте разрешения плагина: ему требуются права на показ OSD-уведомлений, работу с файловой системой и сетевые запросы.
5. Нажмите комбинацию клавиш <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>T</kbd>. Должно открыться окно плагина с зоной Drag & Drop.

## ❓ Часто задаваемые вопросы и решение проблем

### 1. Ошибка «Не удалось подключиться к TorrServer»
- **Причина:** Сервер TorrServer не запущен либо заблокирован брандмауэром.
- **Решение:** Проверьте, доступен ли интерфейс в браузере по адресу [http://127.0.0.1:8090](http://127.0.0.1:8090). Если нет, запустите сервер командой `brew services start torrserver` либо запустите бинарник вручную.

### 2. Окно плагина открывается, но файл не перетаскивается
- **Причина:** Некоторые версии WebKit в macOS могут перехватывать событие drop.
- **Решение:** Просто нажмите на область загрузки — откроется стандартный диалог Finder, в котором можно выбрать нужный `.torrent` файл. Либо воспользуйтесь сочетанием <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>P</kbd>.

### 3. Торрент добавлен, но видео долго не начинает играть
- **Причина:** Раздача не имеет активных сидов либо в торренте отсутствует видеопоток.
- **Решение:** Убедитесь, что у раздачи достаточное количество сидов (рекомендуется от 3–5). Откройте [http://127.0.0.1:8090](http://127.0.0.1:8090) и посмотрите статистику подключения пиров (Peers/Speed).

### 4. Звуковые дорожки и субтитры
Поскольку IINA воспроизводит поток через встроенный движок mpv, все аудиодорожки и встроенные субтитры (в контейнерах MKV/MP4) определяются автоматически и доступны в стандартном меню плеера:
- **Аудио:** Меню **Аудио → Аудиодорожка**.
- **Субтитры:** Меню **Субтитры → Дорожка субтитров**.
